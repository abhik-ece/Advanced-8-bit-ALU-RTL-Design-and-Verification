# Advanced 8-bit ALU RTL Design & Verification

An 8-bit Arithmetic Logic Unit (ALU) designed using SystemVerilog and verified through simulation and waveform analysis. The RTL design was synthesized using Yosys to generate a gate-level netlist.

## Features

The ALU accepts two 8-bit inputs and a 3-bit operation code.

### Supported Operations

| OP | Operation | Description |
|----|-----------|-------------|
| `000` | ADD | `A + B` |
| `001` | SUB | `A - B` |
| `010` | AND | Bitwise AND |
| `011` | OR | Bitwise OR |
| `100` | XOR | Bitwise XOR |
| `101` | NOT | Bitwise NOT of A |
| `110` | SHIFT LEFT | `A << 1` |
| `111` | SHIFT RIGHT | `A >> 1` |

### Outputs

- `RESULT[7:0]` - 8-bit operation result
- `CARRY` - Carry/no-borrow or shift carry flag
- `ZERO` - Indicates whether the result is zero
- `OVERFLOW` - Signed arithmetic overflow flag

## RTL Design

The main RTL module is:

`rtl/alu_8bit.sv`

The design uses SystemVerilog `always_comb` and a `case` statement to select the required operation.

A 9-bit temporary signal is used for arithmetic operations so that the carry generated by addition can be captured.

## Verification & Simulation

The ALU was verified using a self-checking SystemVerilog testbench.

The testbench covers:

- Addition
- Addition with carry
- Subtraction
- Subtraction with borrow
- AND
- OR
- XOR
- NOT
- Left shift
- Right shift
- Signed addition overflow
- Signed subtraction overflow
- Zero flag
- Carry flag

The testbench automatically compares the actual outputs with the expected outputs and reports errors when a mismatch occurs.

### Testbench

`tb/alu_8bit_tb.sv`

### Simulation Tool

Icarus Verilog

### Compile Command

`iverilog -g2012 -o sim/alu_sim rtl/alu_8bit.sv tb/alu_8bit_tb.sv`

### Run Command

`vvp sim/alu_sim`

### Simulation Result

`ALL TESTS PASSED`

## Waveform Analysis

The simulation generates a VCD waveform file:

`sim/alu.vcd`

The waveform can be viewed using GTKWave.

### Open Waveform

`gtkwave sim/alu.vcd`

The waveform is used to verify:

- Input operands
- Operation selection
- Result generation
- Carry behavior
- Zero flag
- Overflow flag

## Synthesis

The RTL was synthesized using Yosys.

`write_verilog -noattr synth/alu_8bit_netlist.v`

`stat`
